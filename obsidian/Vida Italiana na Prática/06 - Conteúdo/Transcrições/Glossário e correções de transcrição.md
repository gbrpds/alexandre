# Glossário e correções de transcrição

As transcrições do YouTube são automáticas e erram nomes italianos. Nas notas de [[Reels e vídeos - índice]] a grafia foi corrigida conforme esta tabela. Se for citar trechos, confira sempre contra o vídeo.

## Como o reconhecimento de voz escreveu → o que é

| Apareceu na transcrição | Correto |
|---|---|
| coestura, postura, questura | **Questura** (delegacia de polícia que cuida de imigração) |
| vídeo, vigili, vídeos (policial) | **vigile / vigili** (polícia local que confere o endereço da residência) |
| permisso de sojouro, sojorno, soggiorno | **permesso di soggiorno** |
| código fiscal, código de fiscalia | **codice fiscale** (equivalente ao CPF italiano) |
| calção, calção (aluguel) | **caução** (depósito de garantia; em italiano, *deposito cauzionale*) |
| Arma de Itália, Armaditária, Arma de Itádia | **Arma di Taggia** (Ligúria, perto de San Remo) |
| Bussanavecchia | **Bussana Vecchia** |
| Piazza del Mercante | **Piazza dei Mercanti** (Milão) |
| trilocália | **trilocale** (2 quartos e sala) |
| Turino | **Turim** (Torino) |
| Canon Hi, Canon RAI | **canone RAI** (taxa da TV estatal, ~9 €) |
| Tare | **TARI** (taxa do lixo) |
| mulejo a longo término | **noleggio a lungo termine** (aluguel de carro de longa duração) |
| abonamento mensilha | **abbonamento mensile** (passe mensal) |
| carta de recepção, carta de hospitalidade | **dichiarazione di ospitalità** |
| Venética | **Veneza / Vêneto** |
| Vito e Alódio | **vitto e alloggio** (comida e moradia) |
| vaglia postal, Vale Postal | **vaglia postale** (ordem de pagamento dos Correios) |
| cruz de tudo | **cru** (sem saber nada) |

## Trechos incertos (marcados entre colchetes nas notas)
- "o seu **LCS** precisa ter sido construído lá atrás" (vídeo [[Vídeo - A Itália real que ninguém te conta no Instagram]]): sigla que não bate com nada; provavelmente outra palavra.
- "No **SL**, o mercado que frequentamos" ([[Vídeo - Custo de vida na Itália]]): nome do supermercado não identificado.

## Termos italianos do dia a dia
| Termo | Significado |
|---|---|
| *residenza* | residência registrada na prefeitura (Comune) |
| *ricevuta* | recibo do pedido de permesso; vale como comprovante de regularidade |
| *ASST* | agência de saúde da Lombardia (onde se escolhe o médico de família) |
| *medico di base* | médico de família do sistema público |
| *graduatoria* | lista de aprovados em concurso, válida por até 2 anos |
| *le ferie estive* | as férias de verão |
| *mutuo* | financiamento imobiliário |
| *termosifoni* | radiadores |
